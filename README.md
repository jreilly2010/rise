# RISE Framework Website

A professional website for the RISE Framework - an internal advancement coaching program for Salesforce employees.

## How to Publish for Free

You have several free hosting options:

### Option 1: GitHub Pages (Recommended)
1. Create a GitHub account at https://github.com
2. Create a new repository named `rise-framework`
3. Upload these files to the repository
4. Go to Settings > Pages
5. Select "Deploy from branch" and choose "main"
6. Your site will be live at `https://yourusername.github.io/rise-framework/`

### Option 2: Netlify
1. Create account at https://netlify.com
2. Drag and drop the `rise-website` folder into Netlify
3. Your site will be live instantly with a free subdomain
4. Optional: Connect a custom domain

### Option 3: Vercel
1. Create account at https://vercel.com
2. Import the project from GitHub or upload directly
3. Instant deployment with free hosting
4. Optional: Add custom domain

## Files Included
- `index.html` - Main website structure
- `styles.css` - All styling and responsive design
- `script.js` - Smooth scrolling and animations

## Customization
- Update email in the CTA button (currently: justine.reilly@salesforce.com)
- Add your photo or headshot in the "About Your Coach" section
- Modify colors in `styles.css` by changing the CSS variables in `:root`
- Add testimonials or success stories as needed
